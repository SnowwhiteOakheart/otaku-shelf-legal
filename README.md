# Otaku Shelf Legal

Domainunabhaengige rechtliche Seiten fuer Otaku Shelf:

- [Datenschutz / Privacy Policy](https://snowwhiteoakheart.github.io/otaku-shelf-legal/datenschutz.html)
- [Impressum](https://snowwhiteoakheart.github.io/otaku-shelf-legal/impressum.html)

Das Repository besitzt absichtlich keine Custom Domain. Die stabile
`github.io`-Adresse kann dadurch in Google Play, App Store Connect und der App
selbst verwendet werden, auch wenn die Hauptdomain von Otaku Shelf wechselt.

Aenderungen auf `main` werden automatisch ueber GitHub Pages veroeffentlicht.
